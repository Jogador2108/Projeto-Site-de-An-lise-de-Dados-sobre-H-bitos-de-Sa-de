# Projeto de Análise de Dados - Hábitos de Saúde

Este projeto apresenta uma análise exploratória de dados sobre hábitos de saúde e bem-estar, desenvolvido como tarefa escolar.

## 📊 Sobre o Projeto

Análise realizada com base em dados coletados através de questionário sobre:
- Frequência de atividade física
- Consumo de frutas e bebidas açucaradas
- Padrões de sono
- Tempo em dispositivos móveis

## 🛠️ Tecnologias Utilizadas

- **HTML5** - Estrutura do site
- **CSS3** - Estilização e design responsivo
- **GitHub Pages** - Hospedagem

1. Faça o download dos arquivos
2. Abra o arquivo `index.html` em seu navegador
3. Ou acesse via GitHub Pages (se hospedado)

## 📈 Principais Insights

- Baixa frequência de atividade física entre participantes
- Consumo elevado de bebidas açucaradas
- Padrões de sono insuficientes
- Grande variação no tempo de uso de dispositivos móveis
